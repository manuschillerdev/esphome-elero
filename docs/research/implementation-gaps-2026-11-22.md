# Elero implementation review, 22 November 2026

Compared the [dev firmware at 554d546](https://github.com/manuschillerdev/esphome-elero/tree/554d546b5f9a086ee7d4b8ec5373b1ab92915789) with Elero’s developer kit, receiver manuals, and field tests. Issues 91 and 92 record the findings before the status and packet-length fixes. [Hardware questions](https://github.com/manuschillerdev/esphome-elero/issues/91) · [Implementation issue](https://github.com/manuschillerdev/esphome-elero/issues/92)

| Area | Result at this revision |
|---|---|
| Basic keys and receiver status | All five Easy Control keys and all 22 manufacturer status labels are present. Status 0F gives the bottom endpoint. A scene or deletion report preserves the last operating state. The models that send the five Sombrero-only values by radio remain open. [Status changes](https://github.com/manuschillerdev/esphome-elero/pull/94) |
| Variable length | The codec handles variable destination lists and preserves trailing bytes for supported frame types. Their meaning depends on the frame. The manufacturer filing gives sizes including physical-layer overhead. [Codec changes](https://github.com/manuschillerdev/esphome-elero/pull/95) |
| Status interpretation | The firmware labels 07 a communication timeout. Elero describes a receiver timeout. During the short interval after STOP, the hub ignores 0E even though it confirms the top endpoint. [Warning](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/elero_packet.cpp#L297) · [Endpoint handling](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/cover_sm.cpp#L166) |
| Preset recall and dimming | TILT can report opening before the direction of travel is known. A light ON reply during a timed dim clears the timer that schedules release. [Cover](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/cover_sm.cpp#L181) · [Light](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/light_sm.cpp#L48) |
| Short press and group STOP | The hub's single-button prefix defaults to 00 03. The TempoTel used 00 04 for the recorded tap. Both caused continuous UP on channel 1. For a group STOP the hub addresses each member separately. The TempoTel sent 45/10 with the four selectors. Native all-channel delivery and behavior through relays remain open. [Button defaults](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/elero_packet.h#L207) · [Group dispatch](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/device_registry.cpp#L555) |
| Pairing | The hub requires UP first and marks the sequence complete after it sends the final command. Invio specifies DOWN first and receiver confirmation. The hub sends basic P (80). It recognizes group P (81) and targeted P (84) on receive. The radio exchange for successful pairing and deletion still needs verification. [Pairing code](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero/learn_in_manager.cpp) |
| Packet inspection | The web interface omits the full ordered selector list. It labels release and status request from the key alone. Saved receivers can bypass submitted raw header fields. The decoder drops unsupported frame types before inspection. [Packet display](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero_web/frontend/app/src/components/packet-table.tsx#L121) · [Raw command handler](https://github.com/manuschillerdev/esphome-elero/blob/554d546/components/elero_web/elero_web_server.cpp#L467) |
| Documented operations without a verified hub action | Store, overwrite or clear either preset. Read or set Auto/Manual. Set JA Pulse step duration. Open ordinary or synchronous learning from a paired remote, select a receiver, end learning at the receiver, or delete one or all links. Apply timer priority or shading control. Load-specific slider actions, sensor fields and scene operation also need radio evidence. The manual fixes the receiver effect. A new key, an existing key sequence, or a transmitter-local action must be established separately for each function. [Elero manuals](../manuals/README.md) |

The next TempoTel experiment with a distinct receiver effect is to query Auto/Manual, change the mode, and verify the receiver's mode independently. The USB editor in Sombrero alone cannot establish that radio exchange.

The hardware test used firmware d059f8f. The Heltec accepted group DOWN and then STOP 2.2 seconds later. One receiver reported moving down and then stopped. The other three reported bottom. Only one receiver confirmed a stop during travel.
